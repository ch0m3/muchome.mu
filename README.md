# muchome.mu
Muchome.mu is Muchome's official website. The website will be doing two primary things for now: displaying Muchome's gallery and allowing people to listen to mixes from Muchome's SoundCloud account.


Muchome means to express yourself. 



    <h3>Muchome means express yourself. </h3>
    Muchome is derived from the Swahili slur "Kuchoma" which means "express yourself."

<h3>Muchome is also a dj duo formed by CH0M3. & Mukobi.</h3>
